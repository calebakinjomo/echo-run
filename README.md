Echo Run is a 2D co-op platformer where you team up with your own ghost: every run is recorded, and your echo replays it — its weight holds plates and opens doors you cannot hold alone. Four levels, orbs to collect, spikes and pits to survive, and a ticking clock.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 in a desktop browser
```
